## 合并规则（回顾）

- **CSV**：以 `(主题, 数据点, 统计起止日, 基期, 数值类型, 指标口径类型, 单位)` 为复合主键；实际值行按身份去重（仅合并 1799 vs 1799.2 这类取整差异），取最权威行（优先 `数据性质=实际` / 高可信度 / 真实 URL / 数值非空 / 备注更丰）；推算/预计行各自保留，确保最全面。
- **现象素材库**：按稳定 `id` 取并集；兼容两种原始格式（wrapper 对象 / 顶层数组），统一归一化；同 id 多版本取最完整条目。
- **零虚构**：所有数值与来源均来自真实公开报告，无 URL 处标注 D 级 + 替代验证说明；推算/预计与实测严格分离。
