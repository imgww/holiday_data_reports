# 节日消费数据采集报告

本项目系统采集并整理了 2023–2026 年节日消费数据，涵盖出游人次、旅游收入、交通客运、消费零售等多维度指标，数据来源公开渠道（holiday-data-fetch v1.2 采集规范）。

每个 `YYYY_假期/` 目录下的文件说明：



| 文件                         | 说明                                                    |
| -------------------------- | ----------------------------------------------------- |
| `snapshots/`               | 原始网页快照，按 `来源机构_标题摘要.html` 命名；快照未存的条目在 JSON 中标 `未存-原因` |

| `round_YYYY-MM-DD-R#.json` | 各观测轮次增量文件（R1–R6），已合并入主 JSON                           |

## holiday-data-fetch.json 数据格式

### 顶层结构



```
{

&#x20; "schema": "holiday-data-fetch-v1",

&#x20; "items": \[ ... ]

```

| 字段                       | 说明                         | 示例                                        |

### 数据层级体系



| 层级 | 说明                                      |
| -- | --------------------------------------- |
| L1 | 结构化统计层：可入趋势线的统计值（22 字段口径对齐）             |
| L2 | 现象素材层：榜单 / 区间 / 定性 / 政策事件 / 平台热点等，轻量标签化 |

> 同一来源可同时入 L1 与 L2（同源双录）；推算 / 测算 / 弱溯源 / 定性类强制 D 级可信度，与实测分栏。

| 轮次 | 日期示例       | 说明         |
| -- | ---------- | ---------- |
| R1 | 2026-08-28 | 首轮采集       |
| R2 | 2026-08-31 | 第二轮补充      |
| R3 | 2026-09-09 | 第三轮修正      |
| R4 | 2026-09-09 | 第四轮校验      |
| R5 | 2026-09-09 | 第五轮补充      |
| R6 | 2026-09-09 | 第六轮补采 / 收官 |

## 门禁与数据纪律



* 行数门禁：春节 / 十一 ≥35（丰富线 60）、五一 / 端午 ≥25（丰富线 45）、暑假 ≥30（丰富线 55）；全部目录达标。

* 全源覆盖：A（政务）+ B（行业 ≥2 机构）+ C（平台 ≥3 平台）必采，E/F 至少一组；地方政务 ≥3 省市。

* 指标维度覆盖：10 核心维度（出游人次 / 旅游收入 / 交通 / 社零 / 支付 / 出入境 / 分省 / 酒店 / 景区 / 派生）≥7 通过。

* 快照覆盖率 ≥80%（本轮条目）；推算 / 测算 / 弱溯源 / 定性强制 D 级；禁止编造数据、无 URL 不入库、旧闻剔除。
