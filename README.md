# 节日消费数据采集报告

本项目系统采集并整理了2023年起节日消费数据，涵盖出游人次、旅游收入、交通客运、消费零售等多维度指标，数据来源公开渠道。

## 数据覆盖范围

| 年份 | 春节 | 五一 | 端午 | 暑假 | 十一 |
|------|:----:|:----:|:----:|:----:|:----:|
| 2023 | ✓ | ✓ | ✓ | ✓ | ✓ |
| 2024 | ✓ | ✓ | ✓ | ✓ | ✓ |
| 2025 | ✓ | ✓ | ✓ | ✓ | ✓ |
| 2026 | ✓ | ✓ | ✓ | ✓ | — |

> 2026 年十一假期数据尚未采集（假期未至）。

```
data-260828-skill-1.2/

│   ├── holiday-data-fetch.json # 结构化采集数据
```

每个 `YYYY_假期/` 目录下的文件说明：

| 文件 | 说明 |
|------|------|
| `snapshots/` | 原始网页 HTML 快照，按 `来源机构_数据描述.html` 命名 |
| `holiday-data-fetch.json` | 结构化采集数据，含 schema、meta 和 items |
| `采集日志.csv` | 采集过程日志，记录每条数据的检索关键词、来源、快照路径等 |

## holiday-data-fetch.json 数据格式

### 顶层结构

```json
{
  "schema": "holiday-data-fetch-v1",
  "meta": { ... },
  "items": [ ... ]
}
```

### 数据层级体系

| 层级 | 说明 |
|------|------|
| L1 | 核心官方指标（出游人次、旅游收入等） |
| L2 | 分项/省级数据 |
| L3 | 补充指标（交通、消费、影视等） |

### 观测轮次

数据采用多轮次采集机制，每轮次对已有数据进行补充和修正：

| 轮次 | 日期 | 说明 |
|------|------|------|
| R1 | 2026-08-28 | 首轮采集 |
| R2 | 2026-08-31 | 第二轮补充 |
| R3 | 2026-08-31 | 第三轮修正 |
| R4 | 2026-09-01 | 第四轮校验 |
