“五一”期间，中心城区解放碑、观音桥、杨家坪、南坪、三峡广场五大商圈消费总额同比增长9.2%。光环购物公园接待游客11万人次，销售额480万元。

据重庆市文化和旅游数据中心初步测算，“五一”期间，接待国内游客1858.31万人次，同比增长10.4%，国内游客花费151.71亿元，同比增长16.3%。

全市重点监测的130家景区累计接待游客793.9万人次，同比增长20.15%。游客量排名前五的景区分别为：荣昌夏布小镇89.11万人次，洪崖洞民俗风貌区69.8万人次、武隆喀斯特旅游区54.5万人次、磁器口古镇52.7万人次、重庆动物园43.1万人次。

全市重点监测的旅游休闲街区累计接待323.9万人次，同比增长38.59%。接待游客人次排名前3的街区分别为：十八梯传统风貌区79.9万人次，南岸弹子石老街34.5万人次，南岸龙门浩老街33.9万人次。

// 南京：位居全国热门旅游目的地首位，30+百货、综合体5天销售额9.4亿元

南京市商务局数据显示，假期五天，南京市商务局重点监测的100余家商贸流通企业共实现销售(营业)额25.7亿元，同比增长6.3%。重点监测的30余家百货、综合体假期五天共实现销售额9.4亿元，同比增长6.4%。

据美团旅行数据，“五一”假期，南京位居全国热门旅游目的地首位，从游客结构来看，外地游客尤其是跨省游客占比增幅显著。此外，美团数据显示，“五一”假期，南京由异地游客贡献的餐饮堂食线上订单量同比增长超50%，烤鸭、盐水鸭、汤包均为平台用户热搜特色美食，南京新街口商圈入选全国吃喝玩乐最火商圈名单。

// 苏州：100家重点商贸企业预计销售13.1亿元，同比增长5.5%

数据监测结果显示，截至5月5日20时，全市纳入统计监测的141处旅游吸引物共接待游客1205.7万人次，同比增长21.4%。此外，节日期间，全市商贸企业积极响应“五五购物节”，推出丰富的促消费活动，全市100家重点商贸企业预计实现销售额13.1亿元，同比增长5.5%。

其中，苏州高新区狮山市集成为文化消费新亮点，全国50余家博物馆、文博机构携1000余款文创好物集中亮相，狮山商圈客流量提升20%，销售额增长24%，多家酒店入住率达100%。

// 杭州：全市五大行业总消费额157.36亿，零售行业消费总额大增28.4%

据“杭州消费在线”监测，“五一”期间（4月30日-5月4日），全市批发、零售、餐饮、住宿和娱乐五大行业总消费金额为157.36亿元，同比增长9.0%；其中，消费品以旧换新政策拉动成效显著，零售行业消费总金额107.11亿元，同比大增28.4%。

湖滨商圈聚焦“首发首展”，联动湖滨银泰in77、工联CC、湖滨88、解百、衣之佳等消费地标，推出蜡笔小新35周年原画全球首展等活动，节日期间实现消费金额2.15亿元，消费笔数81.4万笔，同比增长3.5%。

吴山商圈打造国潮好物集聚地，清河坊步行街推出吴山风物市集等沉浸式文旅体验活动；西湖银泰“耍”烘焙全国首店开业，联合23个面包品牌举行西湖面包节。节日期间实现消费金额0.83亿元，同比增长20.29%。

钱江新城商圈立足高端潮享引力场，万象城首推香奈儿梦幻空间限时香氛展，后续将联动20余个国际知名美妆品牌推出2025杭州万象城香氛节；砂之船推出“五一”专属折扣；非标社区商业中心芳塘推出露天艺术派对绘风日。节日期间实现消费金额5.37亿元，同比增长16.3%。

武林商圈首秀、首展不断，杭州中心无边界主理空间POPLab正式开放、GOODEES全国首站快闪独家登陆；嘉里中心开展TheMonsters森林秘密基地LABUBU全国首展。节日期间客流量226.13万人次，同比增长36.79%；销售额3.1亿元，同比增长7.19%。

// 宁波：全市旅游总收入91.47亿，50家重点监测样本企业销售额7.56亿

据文旅数智通监测数据，截至5月5日18时，宁波市累计接待游客795.4万人次，同比增长10.5%；实现旅游总收入91.47亿元，同比增长8.61%。

据宁波市商务局统计数据，4月30日-5月4日，宁波市50家重点监测样本企业合计实现销售额7.56亿元，同比上涨3.77%。

分商品来看，假期饮料等消费需求增长明显，达到1677.24万元，同比增长26%；日用品、服装、鞋帽实现销售额1961.45万元、1.58亿元和2173.44万元，分别同比上涨5%、7.4%和31.4%；家电和通讯器材销售额达6651.11万元和1592.7万元，分别同比增长13.8%和24.1%；新能源汽车整体实现销售额1.61亿元，同比增长18.3%；餐饮实现营业额3818.23万元。

// 厦门：厦门酒店订单量同比增长近10%；鼓浪屿上岛人数日均超4.5万人次

携程数据显示，“五一”假期，厦门酒店订单量同比去年增长近10%，入境游订单同比去年增长104%。

假期，第十一届鼓浪屿诗会、诗歌快闪、诗歌沙龙、鼓浪屿美院的“岛屿重回计划·溯洄”等活动在琴岛登场。数据显示，假期前四天鼓浪屿上岛人数均超过4.5万人次，接近最大承载量。

园博苑以“园博十二时辰·乐动五一”为主题，推出全天候文旅体验模式，特别策划明清园厦门艺术展、大地花卉展、金榜祈福仪式等活动，假期5天，景区共接待游客近15万人次。

新推出的“屿见闽南·时光幻境”主题景区，共接待游客超20000人次。

// 福州：吃喝玩乐服务消费规模同比增长24%

据美团旅行数据显示，“五一”假期期间，福州吃喝玩乐服务消费规模同比增长24%，外地游客日均消费同比增长68%。携程数据显示，“五一”假期期间，福州酒店订单量同比增长23%。

福州鼓楼区主要景区游客总人数约121.33万人次，其中三坊七巷景区（含乌山）游客人数约94.21万人次；福州西湖等A级景区游客人数约27.12万人次。

// 武汉：入境游订单量同比增长66%，巴公房子单日客流超过10万人次

五一假期，武汉酒店订单量同比增长8%，门票订单量增长近35%，入境游订单量同比去年增长66% 。主要客源地为：上海、北京、长沙、深圳、广州。热门景区包括：黄鹤楼、晴川阁、武汉动物园、东湖、东湖游船。五一假期，博物馆迎来观展热潮，文创产品销售火爆，网红冰箱贴、集章册等成为游客打卡新宠；音乐剧、音乐节轮番上演，为游客提供"文化+娱乐"的多元体验。

“五一”假期首日，江岸区巴公房子单日客流超过10万人次；咸安坊客流量7万人次，同比增长350%。

// 长沙：假期前四天总销售99.89亿元，重点零售企业同比增长超8%

银联商务数据显示，5月1日至4日，长沙市消费总额达99.89亿元，同比增长16.04%。美团公布的全国TOP10热门目的地榜单中，长沙排名全国第六，假期5天长沙共接待游客811.07万人次，同比增长31.4%。

此外，长沙市重点受监测的零售企业5月1日-4日零售总额较2024年同期增长超8%，通讯器材和汽车销售尤为火爆，同比分别上涨110.14%和42.73%；受监测的餐饮企业营业收入较2024年同期增长17.84%。

五一商圈管委会数据，5月1日至4日，五一商圈核心区累计客流量达437.27万人次，重点街区实时客流峰值达24.1万人，较去年增长34.38%。另据悉，五一假期前四天，长沙万象城单日客流均超10万，砂之船（长沙）奥莱客流同比增长30%，销售额增长23%。

// 西安：全市接待游客1475.08万人次，10大商业综合体营收同比增长15.63%

今年“五一”假期，西安文旅创新市场供给，推出多元业态，释放消费潜力，尽显文旅蓬勃生机。据测算，全市接待游客1475.08万人次，同比增长5.2%；游客总花费123.34亿元，同比增长7.55%。

秦始皇帝陵博物院、陕西历史博物馆、西安博物院分别接待游客33.39万人次、6.92万人次、8.38万人次，同比分别增长16.1%、19.9%、125.8%。重点监测的10大商业综合体营收同比增长15.63%。

// 济南：全市30家景区共接待游客393.27万人次，收入1.30亿元

“五一”假日期间，济南市纳入重点监测的天下第一泉、千佛山等全市30家景区共接待游客393.27万人次，实现营业收入1.30亿元，同比分别增长4.49%、3.88%。

重点监测的鲁能贵和洲际、喜来登、山东大厦、鸿腾国际、九如山民宿、若谷山居民宿等20家旅游住宿设施累计接待2.97万人次，实现营业收入2711.83万元。五一假期，旅馆业接待持证留宿旅客75.9万人，同比增长14.8%。

五一假期，济南入境游暴涨138%。

// 青岛：重点监测企业销售额4.12亿元，“电影+文旅”消费火热

监测数据显示，“五一”期间，青岛重点监测企业累计实现销售额4.12亿元，同比增长11.0%。

在以旧换新优惠政策推动下，“五一”期间家电累计核销9.97万台，交易金额2.86亿元；3c数码累计核销3.51万台，交易金额8995万元；家装厨卫累计核销2901台，交易金额619.3万元；汽车板块报废、置换更新共申领1111辆，销售金额1.59亿元。

西海岸新区“五一”期间举办“欢度五一”主题促消费活动60余场，日均客流量达近50万人次,同比增长17%；日均销售额5000余万元,同比增长18%；10家重点餐饮企业日均营业收入86万元，同比增长16%。

华表奖“后劲”发力，形成“电影+文旅”消费新热点。“五一”假期期间，青岛多个影视“打卡地”人气爆棚，《送你一朵小红花》的取景地太平山索道5月2日预估接待游客近8000人次。

// 昆明：国内旅游消费136.96亿元，入境游订单同比增长127%

2025年“五一”假日期间，昆明市累计接待国内游客1261.27万人次，同比增长7.29%，累计实现国内旅游花费136.96亿元，同比增长11.00%。

携程数据显示，“五一”假期昆明市上榜入境游热门目的地前10，入境游订单同比增长127%。

// 沈阳：接待游客1003.62万人次，文旅消费规模全国排名第17

沈阳市累计接待国内游客1003.62万人次，较去年同期增长21.65%；实现国内出游花费105.87亿元，同比增长16.53%，突破百亿大关。

携程、同程数据显示，“五一”假期，辽宁在线旅游预订人次同比增长45.24%，在线旅游消费金额同比增长53.44%。根据美团平台数据显示，“五一”假期前四天，沈阳市文旅消费规模在全国排名第17，东北排名第1。

飞猪数据显示，沈阳、大连、锦州、丹东、葫芦岛是辽宁省内热门目的地城市，北京、吉林、黑龙江、山东、上海等是前往沈阳旅游的热门客源地。

// 海南：入境游订单同比暴涨230%，海口海关离岛免税购物金额5.1亿元

携程数据显示，“五一”假期（2025年5月1日至5月5日），海南入境游订单同比增长230%。飞猪发布的《2025年“五一”假期出游快报》显示，“五一”假期海南的酒店订单量同比增长超20%。

三亚：据三亚发布微信公众号消息，“五一”假期，三亚共接待游客88.75万人次，同比增长15.88%；游客总消费20.93亿元，同比增长8.28%。

海口：据统计，五一假期累计接待游客总人数106.57万人次，同比增长27.26%；游客总花费14.62亿元，同比增长57.55%。

此外，据海口海关统计，“五一”假期（2025年5月1日至5月5日），该关共监管离岛免税购物金额5.1亿元，购物人数7.91万人次。

// 安徽：259家零售企业实现销售额9.37亿，31家餐饮业销售收入0.98亿

安徽省商务厅数据显示，全省重点监测的290家样本企业共实现销售额10.35亿元，同比增长8.09%。其中，全省重点监测的259家零售企业共实现销售额9.37亿元，同比增长8.39%；重点监测的31家餐饮业销售收入0.98亿元，同比增长5.24%。
